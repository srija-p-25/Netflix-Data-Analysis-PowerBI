# 🎬 Netflix Data Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard that analyzes Netflix movies and TV shows to uncover insights into content distribution, release trends, genres, and other key attributes.

The dashboard transforms raw Netflix data into meaningful visualizations to help users understand Netflix's content library.

## 🎯 Project Objectives

- Analyze the distribution of Movies and TV Shows.
- Explore content released across different years.
- Identify popular genres and content categories.
- Examine content distribution across countries.
- Present key insights through interactive visualizations.

## 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculations, where applicable
- **Data Visualization** – Charts, KPIs, and interactive filters

## 📊 Dashboard Features

- **Content Type Analysis:** Compare Movies and TV Shows.
- **Release Year Analysis:** Explore how content releases have changed over time.
- **Genre Analysis:** Understand the distribution of content across genres.
- **Country Analysis:** Examine Netflix content by country.
- **Interactive Visuals:** Use filters and slicers to explore the data.

## 🔍 Key Business Questions

1. How many Movies and TV Shows are available in the dataset?
2. How has Netflix content distribution changed over the years?
3. Which genres have the highest representation?
4. Which countries contribute to the Netflix content library?
5. What patterns can be identified from the release-year trends?
